## Как пользоваться

### 👩‍🏫 Учитель (панель управления)

1. Откройте **https://school-vote-teal.vercel.app/admin/**
2. Войдите с email и паролем (создаётся один раз через Firebase Console → Authentication)
3. **Выберите класс** в выпадающем списке
4. **«Создать данные»** — инициализирует вопрос и варианты ответов.  
   Вопрос: *«Какой формат выпускного?»*, варианты: Ресторан, Пикник в парке, Квест по городу, Кинотеатр + пицца
5. **Таймер** — установите время окончания голосования
6. **PIN-код** — установите (опционально), ученики введут его перед голосованием
7. **«Начать голосование»** — создаёт новую сессию, обнуляет голоса, генерирует QR-код
8. **Список проголосовавших** — кто уже отдал голос (без указания варианта — тайное голосование)

#### Управление классами

- **➕** — добавить новый класс
- **🗑** — удалить класс и все его данные
- **🧹** — удалить мусорные ключи из Firebase (ключи без поля `question`)
- **«Сбросить все голоса»** — очищает голоса, избирателей, сессию, таймер и PIN

### 👨‍🎓 Ученик (голосование)

1. Откройте страницу по QR-коду с проектора или напрямую:  
   **https://school-vote-teal.vercel.app/?class=9А&s=abcde**
2. Если класс не указан в URL — выберите его из списка
3. **Введите имя** — оно отобразится в списке проголосовавших
4. Если учитель установил PIN — введите его
5. Нажмите на вариант ответа — появится конфетти и сообщение «Спасибо, ваш голос принят!»
6. **Повторное голосование невозможно** — защита на 3 уровнях: localStorage + fingerprint + Firebase

### 🖥 Проектор (результаты)

1. Откройте **https://school-vote-teal.vercel.app/results.html**
2. Выберите класс из выпадающего списка
3. Отображаются:
   - **Круговая диаграмма** (Chart.js) с распределением голосов
   - **Процентные полосы** с количеством голосов и %
   - **QR-код** — наведите телефон для перехода к голосованию
   - **PIN-код** — если установлен учителем
   - **Таймер** — обратный отсчёт до завершения
4. **☰** (бургер) — список проголосовавших (имена, без указания варианта)
5. **📥 CSV** — экспорт результатов в CSV
6. **🖼 PNG** — экспорт скриншота в PNG
7. QR-код можно увеличить кликом — откроется модальное окно

## Быстрый старт (для разработчика)

### 1. Проект Firebase

1. Зайдите на https://console.firebase.google.com
2. **«Создать проект»**, отключите Google Analytics
3. **Realtime Database** → **«Создать базу данных»**, тестовый режим
4. Скопируйте URL базы данных

### 2. Настройка

Откройте **`firebase-config.js`** и замените значения на свои.

### 3. Firebase Auth (для входа в админку)

1. Firebase Console → **Authentication** → **Sign-in method** → **Email/Password** → включить
2. **Users** → **«Add user»** → создайте email и пароль учителя
3. Скопируйте **UID** этого пользователя
4. Откройте **`firebase.rules.json`** — замените `ADMIN_UID` на реальный UID
5. Опубликуйте правила в Firebase Console: Realtime Database → Rules

### 4. Деплой на Vercel

```bash
vercel --prod
```

## Структура Firebase

```
poll/
  {classId}/
    question          — текст вопроса
    options/          — массив вариантов {id, text, votes}
      {id}/votes
    totalVotes        — общее количество голосов
    voters/           — избиратели
      {fingerprint}/  — только {name, timestamp} (без optionId)
    sessionId         — ID текущей сессии (меняется при новом запуске)
    timerEnd          — дата/время окончания (ISO 8601)
    pin               — PIN-код для доступа (опционально)
```

## Важные детали

- **Безопасность**: правила Firebase (`firebase.rules.json`) — администратор (по UID) имеет полный доступ, ученики могут только увеличивать голоса и добавлять себя в voters
- **Тайное голосование**: в `voters/{fingerprint}` хранится только `{name, timestamp}`, без `optionId`
- **Защита от повторного голосования**: localStorage → fingerprint → Firebase voters
- **Cache busting**: `?v=11` на всех локальных ассетах. При изменениях увеличивать номер.
- **QR-код** содержит `?class=...&s=...`, автообновляется при смене сессии
- **Конфетти** при успешном голосовании (canvas-confetti)
- **Все надписи на русском**
- **Нет тестов, линтера, typecheck**
